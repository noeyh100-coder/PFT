# 포켓몬 TFT

브라우저에서 돌아가는 포켓몬 오토배틀러입니다. `index.html`을 브라우저로 열면 혼자 하기(봇 7명)가 바로 됩니다. 친구와 온라인으로 하려면 아래 "온라인 플레이"처럼 서버를 띄워야 합니다.

## 온라인 플레이

- 처음 들어오면 닉네임(2~12글자)만 정하고 게스트로 시작합니다. 닉네임과 프로필 포켓몬은 그 브라우저에만 저장됩니다. 전략가는 접속할 때마다 새로 뽑힙니다.
- **메인 화면**: 배경은 사용자가 준 도트 그림(`img/main/bg.png`, 135x75)을 화면에 꽉 차게 픽셀 그대로 키운 것입니다. 왼쪽 위에 프로필(포켓몬 아이콘·닉네임)과 그 아래 **전적** 버튼(아직 준비 중), 오른쪽 위에 배치 도구와 설정, 왼쪽 아래에 **결투장**·**전략가** 버튼, 오른쪽 아래에 **플레이** 버튼이 있습니다.
- **개인 설정(결투장·전략가)**: 왼쪽 탭(전략가·결투장), 가운데 목록(정렬: 기본·즐겨찾기 먼저·이름순, 돋보기로 이름 검색), 오른쪽 미리보기(하트 = 즐겨찾기, 장착). 칸을 누르면 미리보기, 두 번 누르거나 장착을 누르면 적용됩니다. 결투장은 내 필드 맵(무작위 또는 9개 지방, 미리보기는 `img/map/<id>.jpg`), 전략가는 무작위 또는 57명 중 하나(모자 쓴 트레이너·트레이너·어르신 트레이너로 묶음, `STRAT_GROUPS`)입니다. 고른 것은 이 브라우저에 저장되고(`ptft-map-pick`, `ptft-look-pick`) 온라인 파티에서도 그대로 쓰입니다(hello의 `look`·`map` → 서버 seats → `Game`).
- **설정**: 닉네임 바꾸기, 프로필 포켓몬 고르기, 전략가 다시 뽑기(무작위로 되돌림, 고정은 개인 설정에서), 서버 연결 상태.
- **파티 화면**: 플레이를 누르면 내 파티가 바로 만들어집니다. 왼쪽 큰 칸이 나, 오른쪽 7칸이 파티원이고 방장에게는 왕관이 붙습니다. 왼쪽 아래의 5글자 방 코드를 친구에게 알려 주면, 친구는 자기 파티 화면에서 **참여하기**를 눌러 코드를 넣고 들어옵니다.
- **시작**: 방장만 누를 수 있고 빈자리는 봇이 채웁니다. 파티에 혼자면 서버 없이 바로 혼자 하기(봇 7명)가 시작되고, 서버가 잠들어 있거나 연결이 안 될 때도 혼자 하기로 시작됩니다.
- 게임 중 창을 닫거나 새로고침해도 같은 브라우저로 다시 들어오면 이어서 합니다. 자리를 비운 동안에는 봇이 대신 굴립니다.
- **게임이 끝나도 방이 남습니다.** 순위 창의 **파티로 돌아가기**를 누르면 같은 방 코드의 파티 화면으로 돌아가고, 방장이 다시 시작할 수 있습니다. 먼저 탈락한 사람도 탈락 창에서 파티로 돌아가 기다릴 수 있고(게임 진행 중으로 표시), 게임이 끝나면 바로 다음 판을 함께 시작합니다. 나간 사람은 파티에서 빠집니다.
- 모든 플레이어의 화면은 서버가 나눠 주는 행동 기록으로 똑같이 계산됩니다 (서버는 기록만 전달). 준비 완료는 살아 있는 사람이 모두 눌러야 바로 넘어가고, 온라인에서는 속도 조절과 개발 도구가 꺼집니다.

### 내 컴퓨터에서 띄우기

Node.js 18 이상이 필요합니다.

```
npm install
npm start
```

브라우저에서 `http://localhost:8080` 으로 들어갑니다. 같은 와이파이의 친구는 `http://내컴퓨터IP:8080` 으로 들어올 수 있습니다.

### 무료로 인터넷에 올리기 (Render)

1. 이 폴더를 GitHub 저장소에 올립니다 (`node_modules`는 빼고).
2. https://render.com 가입 → **New → Web Service** → 저장소 선택.
3. Instance Type은 **Free**, Build Command `npm install`, Start Command `npm start` (폴더에 있는 `render.yaml`을 쓰면 **New → Blueprint**로 자동 설정됩니다).
4. 배포가 끝나면 나오는 `https://….onrender.com` 주소를 친구들에게 공유합니다.

무료 서버는 15분 동안 아무도 없으면 잠들고, 다음 사람이 들어올 때 깨어나는 데 1분쯤 걸립니다. 서버가 다시 시작되면 진행 중인 방은 사라집니다.


## 조작

| 동작 | 방법 |
|---|---|
| 기물 구매 | 상점 카드 클릭, 또는 카드를 끌어 상점 밖에서 놓기(상점 밖으로 나가면 카드가 반투명해짐). 어떻게 사든 대기석의 첫 빈칸으로 들어옵니다. 카드에 마우스를 올리면 도트가 움직이고 창고에 남은 수(예: 7/18)가 나옵니다. 살 때 그 포켓몬의 울음소리가 납니다 |
| 상점 잠금 | 상점 오른쪽 위 자물쇠. 다음 라운드 한 번만 상점이 그대로 유지되고 잠금은 자동으로 풀립니다 |
| 새로고침 보정 | 같은 기물을 2개 이상(별 등급 포함 복사본 기준) 가지고 있으면, 새로고침했는데 그 기물들이 하나도 안 나올 때마다 다음 새로고침에서 그 기물들이 나올 가중치가 15%씩 올라갑니다. 하나라도 나오면 처음으로 돌아갑니다 |
| 상점 반짝임 | 가진 기물은 흰색, 사면 2성이 되는 기물은 은색(★★), 3성이 되는 기물은 금색(★★★)으로 반짝입니다. 3성을 만든 기물은 상점에 나오지 않고, 팔면 다시 나옵니다 |
| 배치·교체 | 기물을 필드나 대기석으로 드래그. 다른 기물 위에 놓으면 서로 자리를 바꿈 |
| 기물 정보 | 기물을 클릭 (내 기물, 상대 기물, 전투 중 기물, 야생 포켓몬 모두 가능). 빈 곳을 클릭하면 닫힘 |
| 정보창 능력치 | 오른 능력치는 노란색. 마우스를 올리면 `공격력 85 (50 + 45)`처럼 기본값과 보너스가 나옵니다. 시너지 아이콘에 마우스를 올리면 시너지 설명이 나옵니다 |
| 진화 계보 | 정보창 왼쪽의 진화 버튼. 정보창 왼쪽에 계보와 진화 조건이 나옵니다. 단계마다 타입과 스킬 이름이 보이고, 앞 단계와 달라진 칸은 노란색입니다. 스킬 이름에 마우스를 올리면 스킬 설명이 나옵니다 |
| 판매 | 기물을 상점으로 드래그, 또는 마우스를 올리고 `E` |
| 빠른 이동 | 기물에 마우스를 올리고 `W`. 대기석 기물은 필드 앞줄 가운데부터 빈칸으로, 필드 기물은 대기석 첫 빈칸으로 갑니다. 갈 곳이 없거나 필드 인원이 꽉 차면 움직이지 않습니다 |
| 다른 필드 순서대로 보기 | `3`은 순위표 아래쪽 플레이어, `1`은 위쪽 플레이어의 필드로 넘어갑니다. 끝에서 반대쪽 끝으로 돌아가고 탈락한 플레이어는 건너뜁니다 |
| 새로고침 / 경험치 | `D` / `F` |
| 전략가 이동 | 결투장에서 오른쪽 클릭 (전리품 구를 먹을 때, 회전초밥에서 기물을 고를 때). 가는 길 위에 전리품 구가 있으면(어디를 클릭했든) 그 구를 먹을 때까지 3배 빠르게 달려갑니다 |
| 전리품 구 | 몬스터볼은 기물·골드, 슈퍼볼은 아이템입니다. 증강이 주는 아이템도 슈퍼볼 구로 내 필드에 떨어집니다. 야생 포켓몬이 쓰러진 자리에 바로 떨어지고, 전투 중에도 주울 수 있습니다. 구 근처를 오른쪽 클릭해도 달려갑니다. 못 주운 구는 전투가 끝나면 자동으로 들어옵니다 |
| 상대 필드 보기 | 오른쪽 목록에서 프로필 클릭. 준비 단계와 전투 중 모두 전략가가 그 필드로 직접 건너가서 오른쪽 클릭으로 돌아다닐 수 있고, 그 필드의 주인에게도 내 전략가가 보입니다. 보는 동안 상점은 숨겨지고, 아래 집 버튼이나 `스페이스바`로 복귀. 전투가 시작될 때와 회전초밥이 시작될 때 모두 자기 필드로 돌아옵니다. 전투 중 내 전투의 상대를 누르면 자리는 그대로 두고 화면만 바뀝니다 |
| 회전초밥 중 화면 전환 | 집 버튼으로 내 필드 보기, 프로필로 다른 필드 보기. 집 버튼을 다시 누르거나 `스페이스바`로 회전초밥 복귀 |
| 플레이어 목록 / 딜량표 | 플레이어 목록 위의 전환 버튼. 딜량표는 오른쪽에서 밀려 들어오고 닫으면 오른쪽으로 나갑니다. 딜량표의 `<` 버튼을 누르면 상대 딜량도 보입니다 |
| 시너지 다음 페이지 | 시너지가 9개를 넘으면 나오는 `+n` 버튼 |
| 시너지 설명 | 시너지 칸에 마우스를 올리면 단계별 효과와 해당 기물 목록이 나옵니다. 필드에 있는 기물은 컬러, 없는 기물은 흐린 색이며, 초상화에 마우스를 올리면 이름·코스트·역할군·시너지가 보입니다. 고유 시너지는 맨 위에 나오고 현재 스택이 함께 보입니다 |
| 다음 상대 | 플레이어 목록에서 체력 왼쪽에 칼 아이콘이 붙은 플레이어 |
| 배치 도구 | 화면 오른쪽 위 모서리의 둥근 버튼. "새 팀"으로 최대 10마리 팀을 짜고(기물 클릭으로 넣고 빼기, 칸끼리 끌어서 순서 바꾸기), 필터로 시너지별 기물만 볼 수 있습니다. 게임 중에는 "지우기" 오른쪽의 "스냅샷"으로 지금 필드의 기물을 팀에 그대로 넣을 수 있고, 시너지가 9개를 넘으면 `+n` 버튼으로 다음 시너지를 봅니다. 팀은 브라우저에 저장되고, 스위치를 켠 팀의 기물은 상점 카드에 몬스터볼이 붙습니다. ← 로 목록에 돌아갈 때 빈 팀은 저장되지 않고, X로 닫으면 보던 화면이 그대로 남습니다. 목록의 기물은 최종 진화체 정지 그림으로 나오고, 마우스를 올리면 애니메이션이 움직이며 미진화체부터 1초마다 진화 단계(그림·타입·직업 아이콘)가 돌아갑니다. 필터는 타입끼리·직업끼리 이름순입니다. 기물에 마우스를 올리면 정보 탭(초상화·이름·코스트·잠김, 역할군, 시너지, 잠긴 기물이면 해금 조건, 진화 계보, 상점 창고 남은 수)이 나옵니다. 진화 계보는 가로 카드와 화살표로 단계마다 도트·이름(코스트)·별·타입과 직업 아이콘·스킬 이름을 보여 주고, 이브이는 가운데에 이브이를 두고 8방향으로 진화형을 보여 줍니다. 배치 도구 창은 증강 카드보다 위에 뜹니다 |
| 시너지 아이콘 | 타입은 타입 색 육각형에 흰 아이콘, 직업은 흑백 아이콘이고 켜지면 단계에 따라 동·은·금(마지막 단계는 무지개빛)으로 바뀝니다. 타입은 테두리 색으로 단계를 보여줍니다. 고유 시너지는 해당 포켓몬 도트가 들어갑니다 |
| 아이템 장착 | 왼쪽 아이템 칸에서 아이템을 끌어 기물 그림 위에 놓습니다(칸이 아니라 기물 기준, 놓을 수 있는 기물은 테두리가 빛남). 언제든 되고, 전투 중인 필드 기물에 주면 그 전투에 바로 적용됩니다. 조합 아이템을 가진 기물에 조합 아이템을 하나 더 주면 바로 완성 아이템이 됩니다. 끌고 가는 동안 조합될 기물 위에 올리면 완성될 아이템이 미리 보입니다 |
| 아이템 칸에서 조합 | 조합 아이템을 다른 조합 아이템 위로 끌어 1초 대고 있다가(테두리가 다 차면) 놓으면 완성 아이템이 됩니다 |
| 아이템 칸 정리 | 아이템을 다른 아이템 위에 놓으면(조합 1초가 차기 전) 두 칸의 자리가 바뀝니다. 빈칸에 놓으면 원래 자리로 돌아갑니다. 자석·사탕처럼 모여 있는 소모품은 묶음째 옮겨집니다 |
| 아이템 설명 | 아이템에 마우스를 올리면 정보창이 뜹니다. 조합 아이템은 오른쪽 클릭으로 조합표(+ 재료 > 결과)를 열고 닫고, 완성 아이템은 아래에 재료 2개가 나옵니다. 정보창 안의 아이콘을 누르면 그 아이템의 정보창이 옆에 하나 더 열립니다 |
| 채굴장 | 땅 시너지의 채굴 스택이 100 단위에 닿으면 준비 단계에 상점이 아래로 내려가고 그 자리에 "채굴장" 패널이 아래에서 올라옵니다(롤토체스 암시장 모양). **모두 받기** / **더 채굴하기**(이번 준비 단계는 넘기고 계속 쌓음). 고르면 상점이 다시 올라옵니다. 채굴 스택은 내 맵 오른쪽 아래의 다크엘릭서 정제소(땅 시너지가 켜졌거나 스택이 있을 때 보임)의 액체 높이와 숫자로도 보입니다 |
| 이상한사탕 | 아이템처럼 기물 위로 끌어 놓으면 별이 1 오릅니다 (모든 코스트, 3성 제외) |
| 경험사탕 | 기물 위로 끌어 놓으면 그 기물의 1성 복사본을 대기석에 얻습니다 (S: 1코, M: 3코 이하, L: 전부) |

| 4 | 1000 / 900 / 850 | 75 |
| 5 | 1200 / 1100 / 1000 | 90 |
| 6 | 5코스트와 같음 (해금 전용 뮤·뮤츠·파이어·썬더·프리져) | 90 |

- 주 공격 배율: 위 표의 수치 ÷ 20 (1코 2.5배 … 5코 4.5배). 물리 계열은 공격, 특수 계열은 특수공격 쪽이 주 배율이고, 다른 쪽은 그 절반입니다. 기본 공격과 스킬 피해 모두 이 배율을 씁니다.
- 숨은 방어 배율: 탱커 2배, 전사 1.5배, 마법사 1배 (예전 방어 40 / 30 / 20과 같은 피해 감소). 공격 속도(초당 기본 공격 횟수): 탱커 0.6, 전사 0.7, 마법사 0.8.
- 별 등급이 오르면 **체력(1 / 1.8 / 3.24배)과 스킬 배율(1 / 2 / 3.5배)만** 강해집니다. 기본 공격·방어·공격 속도는 별 등급으로 바뀌지 않습니다. 그래서 같은 조건의 PvP 평균 전투 시간이 약 22초에서 약 24초로 늘었습니다.
- 해금 기물은 모든 수치가 1.25배입니다. 망나뇽은 체력과 공격이 추가로 1.2배입니다.
- 야생 포켓몬도 같은 공식에 라운드 배율과 0.8배를 곱합니다.
- 피해는 `피해 × 100 / (100 + 방어)`이고, 피해증폭만큼 늘고 내구력만큼 줄어듭니다.

## 라운드 진행

- 해금 기물이 풀리면 화면 위쪽 가운데에 "해금했습니다!" 카드가 약 2.7초 동안 뜹니다(위에서 튀어 내려옴, 회전하는 빛살과 반짝이 효과, 잠긴 자물쇠가 열리는 배지, 그 포켓몬의 울음소리). 여러 개가 동시에 풀리면 차례로 뜹니다.
- 1-1은 조우 라운드입니다(13초). 시작하면 화면이 내 자리를 2배로 확대한 채 검은 화면에서 밝아지고, 8명이 각자 방향에서 아머까오택시를 타고 초밥집 모래판에 내립니다. 내가 내리면 2초 동안 천천히 전체 화면으로 줌아웃하고(그동안 다른 플레이어 택시가 차례로 도착), 줌아웃이 끝나면 위쪽에 조우자 카드(이름·효과)가 페이드 인됩니다. 가운데에는 이번 게임의 조우자 포켓몬이 있습니다. 끝나면 일반 회전초밥처럼 택시가 태워 가고 검게 어두워졌다가 내 맵에 내려 주며, 선물 기물(보통 1코스트, 피카츄는 2코스트, 이브이는 3코스트)을 받습니다.
- 2-1 · 3-2 · 4-2 라운드는 증강 라운드라 준비 시간이 40초입니다. 증강 규칙과 목록은 docs/증강체.md를 보세요.
- 1-2 라운드는 수입이 없습니다. 크립 라운드의 준비 시간은 10초입니다.
- PvP 전투에서 이기면 바로 1골드를 받습니다.
- PvP 전투는 한 플레이어의 맵에서 열립니다. 주인은 아래쪽, 원정 온 플레이어는 기물과 전략가가 위쪽으로 이동합니다. 처음 만나는 상대와는 무작위로, 다시 만나면 번갈아 주인이 됩니다. 원정 전투는 매칭 후 5초 동안 "전투 시작까지" 카운트다운이 있고 그동안 기물을 옮길 수 없습니다. 다음 준비 단계에서 내 맵으로 돌아옵니다.
- 크립 라운드는 항상 내 맵에서 합니다.
- 크립 라운드와 회전초밥에서 아이템을 얻습니다. 시작할 때 자석 4개를 받습니다. 자세한 내용은 docs/아이템.md를 보세요.
- 전략가 이동 속도는 어디서나 예전의 절반입니다 (회전초밥 포함).
- 회전초밥에는 같은 기물이 2번 나오지 않습니다. 진화로 해금되는 이전 단계 기물은 상점에는 나오지 않지만 회전초밥에서는 고를 수 있습니다.
- 원정 전투는 아머까오택시로 이동합니다. 원정 갈 라운드면 준비 시간이 1.5초 남았을 때 택시가 날아와 내 전략가 위에 떠서 따라다니고, 준비 시간이 끝나는 순간 내려와 태워 갑니다(준비 완료로 일찍 끝나면 그때 날아옴). 원정 간 맵에서는 전략가 칸에 내려 그 자리에 놓아 줍니다(5초 카운트다운 안에 끝남). 전투가 끝나면 같은 방식으로 내 맵의 전략가 칸에 돌아오고, 내 맵에 원정 온 상대도 택시로 오고 갑니다.
- 택시를 타기 전(준비 시간 0초)에 필드의 기물이 빨간 빛과 함께 몬스터볼로 빨려 들어가 전략가에게 돌아오고, 그다음 떠 있던 택시가 내려와 태웁니다. 도착해서 내리면 전략가가 기물 자리마다 몬스터볼을 차례로 던져 기물이 튀어나옵니다. 귀가할 때와 상대가 내 맵에 올 때도 똑같습니다. 택시에서 내리면 바로 움직일 수 있고, 다른 필드를 관전 중이면 택시 없이 이동합니다.
- 택시는 태우러 올 때는 전략가 위치, 내려 줄 때는 내릴 자리를 기준으로 화면 가운데보다 왼쪽이면 왼쪽에서, 오른쪽이면 오른쪽에서 오고 같은 쪽으로 떠납니다. 원정을 간 전략가의 위치는 전투 시작과 다음 준비 단계 시작 때 전략가 칸으로 옮겨지고(게임 상태로 동기화됨), 택시 그림 자체는 연출일 뿐입니다.
- 회전초밥 맵은 초밥집입니다: 하늘에 떠 있는 섬 위에 팔각형 자리 8개, 가운데 금색 원판과 아이템이 도는 청록 레일, 자리와 원판을 잇는 나무 계단, 벚꽃 나무가 코드로 그려져 있습니다(`js/ui/projection.js`의 `Floor.sushi`).
- 회전초밥도 택시로 갑니다. 내 맵에서 택시를 타면 화면이 검게 어두워졌다 밝아지고, 8명이 각자 자기 자리 방향에서 택시를 타고 내려옵니다. 끝나면 택시가 모두를 태우고 떠난 뒤 어두워졌다가 내 맵에서 내려 줍니다.
- 펑펑 효과: 전투가 끝나면 이긴 쪽 전략가가 진 쪽 전략가에게 느린 빛 구체를 날리고, 맞는 순간 체력이 깎이며 피해 숫자가 뜹니다(무승부는 서로, 크립 라운드에서 지면 적 쪽에서 날아옴).
- 회전초밥에서 고른 기물과 아이템은 회전초밥이 끝날 때 한꺼번에 들어옵니다. 대기석이 꽉 차 있으면 기물이 필드 앞쪽 빈칸에 들어가고, 전투가 시작될 때까지 그 칸의 육각형에 빨간 테두리가 생깁니다. 그 전에 필드 기물을 팔아 자리가 나면 그대로 전투에 나가고, 대기석 기물을 팔면 대기석으로 옮겨집니다. 전투가 시작될 때도 빨간 테두리가 남아 있으면 그 기물은 판매 가격만큼 골드로 바뀝니다.

## 전투 규칙 요약

- 30초부터 15초 동안 연장전이고, 45초가 지나면 무승부입니다. 자세한 내용은 docs/시너지.md의 "전투 시간과 무승부"를 보세요.
- 체력바는 준비 단계에도 보이고, 100마다 검은 눈금(1000마다 굵은 눈금)이 있습니다. 테두리는 1성 동, 2성 은, 3성 금색입니다.
- PP가 최대치까지 차면 스킬을 씁니다. 최대치는 기물마다 다르고(탱커는 많고 딜러는 적음, docs/아이템.md의 "PP" 참고), 기본 공격할 때, 기본 공격이나 스킬에 맞을 때 1씩 찹니다. 스킬은 기본 공격보다 큰 투사체로 1.5배 피해를 줍니다.
- 랭크는 -6~+6이고, 1랭크마다 15%씩 오르거나 내립니다 (+1은 1.15배, -1은 1/1.15배).
- 급소는 0랭크 4.17%, 1랭크 12.5%, 2랭크 50%, 3랭크 이상 100%이며, 1.5배 피해에 상대의 방어 랭크 상승을 무시합니다.
- 명중 랭크에서 회피 랭크를 뺀 값이 0 이상이면 반드시 맞고, 1 이상이면 피해가 10% 늘어납니다. 음수면 -1에 86%, -6에 50% 확률로 맞습니다.
- 시너지는 필드에 있는 기물만 세고, 같은 기물은 진화 계열까지 묶어 1마리로 셉니다(야돈·야도란, 핑복·해피너스 등). 이때는 코스트가 높은 쪽, 같으면 별이 높은 쪽의 시너지를 셉니다. 메타몽의 복사본은 예외로 따로 셉니다. 야생 포켓몬은 시너지가 없습니다.
- 용의 비늘 스택은 게임이 끝날 때까지 쌓입니다 (개발 도구에서 확인 가능).
- 격투 타입 포켓몬은 처음 체력 50% 이하가 되면 뒷줄 구석으로 물러나 3초 동안 벌크업(무적, 대상 지정 불가)하고, 끝나면 스피드·이동 속도·공격·방어가 오릅니다. 자세한 내용은 docs/시너지.md의 "격투 시너지"를 보세요.
- 에스퍼 효과(매직룸·미러코트·신통력·치유소원·봉인)는 게임 시작 때 무작위로 하나 정해지고 모든 플레이어가 같이 씁니다. 개발 도구의 "에스퍼 효과 변경"으로 바꿔 볼 수 있습니다.

## 전장 맵

- 관동, 성도, 호연, 신오, 하나, 칼로스, 알로라, 가라르, 팔데아 9개 지방 전장이 있습니다. `js/ui/maps.js`에 지방마다 바닥, 테두리, 대기석, 전략가 자리, 이자 받침대, 주변 소품, 하늘이 코드로 그려져 있습니다.
- 게임을 시작하면 8명의 플레이어가 서로 다른 맵을 무작위로 받습니다. 결투장은 지금 보고 있는 플레이어의 맵으로 바뀝니다 (내 필드는 내 맵, 상대를 관전하면 그 상대의 맵).
- 내 맵은 시작할 때 바로 그리고, 나머지 맵은 게임 중에 조금씩 미리 그려 둡니다.
- 맵 순서와 목록은 `js/data/config.js`의 `maps`입니다.

## 이자 표시

- 이자는 받침대 위의 황금 몬스터볼로 표시됩니다 (최대 5개, 이자가 없는 자리는 받침대만 보임).
- 몬스터볼은 버튼이 전장 쪽을 보도록 놓입니다. 내 쪽(왼쪽 아래)은 버튼이 오른쪽 아래, 상대 쪽(오른쪽 위)은 왼쪽 아래를 봅니다.
- 이자가 늘면 받침대 밑에서 튀어나오고, 평소에는 가끔 반짝입니다.
- 그림은 `img/dot/ui/goldball.png`(18×18 도트, 화면에서 2배)와 `img/dot/ui/sparkle.png`입니다.

## 도트 그래픽

- 기물은 8방향(앞, 뒤, 좌우, 대각선)으로 상대를 바라보며, 대기·걷기·기본 공격·스킬·잠듦 동작을 씁니다. 잠듦과 기절은 잠자는 동작, 얼음은 동작이 멈춥니다.
- 기본 공격은 `Attack`, 스킬은 물리면 `Strike`(없으면 `Double`), 특수면 `SpAttack`(없으면 `Shoot`) 동작입니다. 어떤 시트를 쓰는지는 `js/data/sprites.js`의 각 포켓몬 `p` 항목에 있습니다.
- 메타몽이 복사한 기물은 보라색 테두리로 표시됩니다.
