# 포켓몬 TFT

브라우저에서 돌아가는 포켓몬 오토배틀러입니다. 설치할 것 없이 `index.html`을 브라우저로 열면 바로 실행됩니다.

## 조작

| 동작 | 방법 |
|---|---|
| 기물 구매 | 상점 카드 클릭 |
| 배치·교체 | 기물을 필드나 대기석으로 드래그. 다른 기물 위에 놓으면 서로 자리를 바꿈 |
| 기물 정보 | 기물을 클릭 (내 기물, 상대 기물, 전투 중 기물, 야생 포켓몬 모두 가능). 빈 곳을 클릭하면 닫힘 |
| 판매 | 기물을 상점으로 드래그, 또는 마우스를 올리고 `E` |
| 새로고침 / 경험치 | `D` / `F` |
| 전략가 이동 | 결투장에서 오른쪽 클릭 (전리품 구를 먹을 때, 회전초밥에서 기물을 고를 때) |
| 상대 필드 보기 | 오른쪽 목록에서 프로필 클릭. 보는 동안 상점은 숨겨지고, 아래 집 버튼이나 `스페이스바`로 복귀 |
| 회전초밥 중 화면 전환 | 집 버튼으로 내 필드 보기, 프로필로 다른 필드 보기. 집 버튼을 다시 누르거나 `스페이스바`로 회전초밥 복귀 |
| 플레이어 목록 / 딜량표 | 오른쪽 위 전환 버튼. 딜량표의 `<` 버튼을 누르면 상대 딜량도 보입니다 |
| 시너지 다음 페이지 | 시너지가 9개를 넘으면 나오는 `+n` 버튼 |
| 시너지 설명 | 시너지 칸에 마우스를 올리면 단계별 효과와 해당 기물 목록이 나옵니다. 필드에 있는 기물은 컬러, 없는 기물은 흑백이며, 초상화에 마우스를 올리면 이름이 보입니다 |
| 메타몽 연결 (괴짜) | 메타몽을 끌어서 아군 위에 1초 동안 대고 있으면 연결됩니다 (테두리가 다 차면 완료) |
| 먹이 주기 (대식가) | 대기석 기물을 끌어서 먹고자·잠만보 위에 1초 동안 대고 있다가 놓으면 삼킵니다 (준비 단계마다 1번) |
| 준비 완료, 속도, 개발 도구, 크레딧 | 왼쪽 위 아이콘 (개발 도구는 `` ` `` 키로도 열림) |
| 내 전장 맵 바꾸기 | 개발 도구 아래쪽의 지방 버튼 (관동~팔데아) |

## 폴더 구조

```
index.html
css/style.css
fonts/            Galmuri 도트 폰트 (OFL 라이선스)
img/              그림 파일. 넣을 파일 이름은 img/파일목록.md 참고. img/dot/pokemon/영어이름/ 에 포켓몬 도트 시트
js/data/          units.js(기물·야생 포켓몬 데이터), config.js(수치), traits.js(시너지 목록), sprites.js(도트 시트 정보·제작자), regional.js(리전폼 데이터 보관용, 게임에서 불러오지 않음)
docs/             스킬목록.md(기물별 스킬), 시너지.md(용어·타입 상성·독 시너지·고유 시너지)
js/core/          rng.js(시드 난수), hex.js(육각 좌표)
js/game/          게임 로직 (화면과 분리)
js/ui/            assets.js(그림·아이콘), sprites.js(도트 애니메이션), mapkit.js(맵 그리기 도구), maps.js(지방별 전장 9종), view.js(패널·카드), projection.js(2.5D 카메라·바닥), arena.js(결투장·전략가), app.js(진행)
```

## 바꾸고 싶은 수치가 있을 때

대부분 `js/data/config.js`에 모여 있습니다.

| 항목 | 위치 |
|---|---|
| 레벨업 경험치, 상점 확률, 풀 크기 | `xpToNext`, `shopOdds`, `poolSize` |
| 수입, 이자, 연승·연패 보너스 | `baseIncome`, `earlyIncome`, `interest*`, `streakBonus` |
| 패배 피해 | `stageDamage`, `unitDamage` |
| 해금 조건 수치 (임시값) | `unlock` |
| PvE 구성과 강도 | `pve` (별, 배율 `mult`, 보스 체력 배율 `hpMult`, 전리품 구 개수 `drops`) |
| 전리품 구 색깔 확률 | `orbs` |
| 회전초밥 시간·속도 | `carousel` |
| 회전초밥 크기 (전략가 자리 원 반지름, 자리 크기, 모래판 크기) | `js/ui/projection.js`의 `CAROUSEL` |
| 스탯 환산, 역할군 분류 | `js/game/units.js`의 `computeStats`, `roleOf` |
| 경기장 기울기·크기 | `js/ui/projection.js`의 `pitch`(기울기), `height`(원근 강도), `nearWidth`(크기) |
| 기물·전략가 크기 | `js/ui/arena.js`의 `UNIT_SCALE`, `STRAT_SCALE` |
| 도트 크기, 별 등급별 크기 | `js/ui/sprites.js`의 `SPRITE_SCALE`(기본 1.5배), `SPRITE_STAR`(1성 1, 2성 1.15, 3성 1.3) |
| 시너지 단계와 효과 수치 | `js/data/traits.js`의 `TRAIT_DEFS` (`tiers` 단계, `steps` 설명, `vals` 실제 수치). 노말 기물별 효과는 `NORMAL_EFFECTS` |
| PP, 스킬 배율, 급소 확률, 랭크 배율, 명중 보너스 | `js/data/config.js`의 `combat` (`maxMana`, `skillMult`, `critTable`, `critMult`, `rankStep`, `hitBonus`) |
| 투구·프테라 해금 조건 | `unlock`의 `kabutoWins`, `aerodactylLosses` |

## 전투 규칙 요약

- PP는 20이 차면 스킬을 씁니다. 기본 공격할 때, 기본 공격이나 스킬에 맞을 때 1씩 찹니다. 스킬은 기본 공격보다 큰 투사체로 1.5배 피해를 줍니다.
- 랭크는 -6~+6이고, 1랭크마다 15%씩 오르거나 내립니다 (+1은 1.15배, -1은 1/1.15배).
- 급소는 0랭크 4.17%, 1랭크 12.5%, 2랭크 50%, 3랭크 이상 100%이며, 1.5배 피해에 상대의 방어 랭크 상승을 무시합니다.
- 명중 랭크에서 회피 랭크를 뺀 값이 0 이상이면 반드시 맞고, 1 이상이면 피해가 10% 늘어납니다. 음수면 -1에 86%, -6에 50% 확률로 맞습니다.
- 시너지는 필드에 있는 기물만 세고, 같은 기물은 1마리로 셉니다. 야생 포켓몬은 시너지가 없습니다.
- 용의 비늘, 격투 수련 스택, 사이킥 에너지는 게임이 끝날 때까지 쌓입니다 (개발 도구에서 확인 가능). 격투·에스퍼 보상은 아직 비어 있습니다.

## 전장 맵

- 관동, 성도, 호연, 신오, 하나, 칼로스, 알로라, 가라르, 팔데아 9개 지방 전장이 있습니다. `js/ui/maps.js`에 지방마다 바닥, 테두리, 대기석, 전략가 자리, 이자 받침대, 주변 소품, 하늘이 코드로 그려져 있습니다.
- 게임을 시작하면 8명의 플레이어가 서로 다른 맵을 무작위로 받습니다. 결투장은 지금 보고 있는 플레이어의 맵으로 바뀝니다 (내 필드는 내 맵, 상대를 관전하면 그 상대의 맵).
- 내 맵은 시작할 때 바로 그리고, 나머지 맵은 게임 중에 조금씩 미리 그려 둡니다.
- 맵 순서와 목록은 `js/data/config.js`의 `maps`입니다.

## 이자 표시

- 이자는 받침대 위의 황금 몬스터볼로 표시됩니다 (최대 5개, 이자가 없는 자리는 받침대만 보임).
- 몬스터볼은 버튼이 전장 쪽을 보도록 놓입니다. 내 쪽(왼쪽 아래)은 버튼이 오른쪽 아래, 상대 쪽(오른쪽 위)은 왼쪽 아래를 봅니다.
- 이자가 늘면 받침대 밑에서 튀어나오고, 평소에는 가끔 반짝입니다.
- 그림은 `img/dot/ui/goldball.png`(18×18 도트, 화면에서 2배)와 `img/dot/ui/sparkle.png`입니다.

## 도트 그래픽

- 기물은 8방향(앞, 뒤, 좌우, 대각선)으로 상대를 바라보며, 대기·걷기·기본 공격·스킬·잠듦 동작을 씁니다. 잠듦과 기절은 잠자는 동작, 얼음은 동작이 멈춥니다.
- 기본 공격은 `Attack`, 스킬은 물리면 `Strike`(없으면 `Double`), 특수면 `SpAttack`(없으면 `Shoot`) 동작입니다. 어떤 시트를 쓰는지는 `js/data/sprites.js`의 각 포켓몬 `p` 항목에 있습니다.
- 메타몽이 복사한 기물은 보라색 테두리로 표시됩니다.
