# 기물 스킬·아이템 직관 수치 목록

기물 스킬과 아이템의 능력치 표기는 롤체 13시즌식 직관 수치로 통일했습니다. 증강체와 시너지는 기존 랭크 수치와 설명을 유지합니다.

## 변환 기준

| 기존 수치 | 직관 수치 |
|---|---|
| 공격 1랭크 | 공격력 +15% |
| 주문력(특수공격) 1랭크 | 주문력 +15% |
| 공격 속도 1랭크 | 공격 속도 +15% |
| 방어 1랭크 | 방어력 +20 |
| 특수방어 1랭크 | 마법저항 +20 |

기물 스킬의 임시 버프는 전투 시간 동안 더해지며 영구 버프는 전투가 끝날 때까지 누적됩니다. 기존 랭크 계산은 증강체와 시너지를 위해 호환용으로 남아 있습니다.

## 조합 아이템

| 아이템 | 추가 능력치 |
|---|---|
| 힘의머리띠 | 공격력 +10% |
| 박식안경 | 주문력 +10% |
| 방호패드 | 방어력 +20 |
| 스페셜가드 | 마법저항 +20 |
| 순발력깃털 | 공격 속도 +10% |
| 먹다남은음식 | 체력 +150 |
| 과사열매 | 시작 PP +15 |
| 예리한손톱 | 급소율 +1랭크 |

완성 아이템은 재료 두 개의 능력치를 합산하고 고유 효과를 유지합니다. 찬란한 아이템은 능력치 합산값을 두 배로 적용합니다.

## 기물 스킬 적용 예시

| 스킬 설명 기준 | 실제 수치 |
|---|---|
| 공격 1랭크 상승 또는 감소 | 공격력 +15% 또는 -15% |
| 주문력 1랭크 상승 또는 감소 | 주문력 +15% 또는 -15% |
| 공격 속도 1랭크 상승 또는 감소 | 공격 속도 +15% 또는 -15% |
| 방어 1랭크 상승 또는 감소 | 방어력 +20 또는 -20 |
| 특수방어 1랭크 상승 또는 감소 | 마법저항 +20 또는 -20 |
| 방어·특수방어 2랭크 상승 | 방어력 +40, 마법저항 +40 |

기물 스킬의 각 포켓몬별 상세 설명은 `js/data/skilltext.js`의 해당 항목을 따릅니다.

## 검증

- 고정 시드 1000~1023으로 봇 8명 전투를 각 1판 실행해 24판 전부 정상 종료했습니다.
- 같은 시드의 기존 버전과 비교해 새 버전의 평균 등수와 평균 종료 라운드가 동일했습니다.

| 버전 | 평균 등수 | 평균 종료 라운드 |
|---|---:|---:|
| 기존 랭크 버전 | 4.500 | 34.9 |
| 직관 수치 버전 | 4.500 | 34.9 |
| 차이 | 0.000 | 0.0 |

- 전투 계산은 기존 랭크 호환과 새 직관 수치 경로를 분리해 증강체와 시너지 동작을 유지합니다.
